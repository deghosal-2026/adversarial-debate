# Governance

AdversarialDebate is a single-maintainer project (v0.1.0) with a roadmap to community governance.

## Current

- **Maintainer:** Debashish Ghosal
- **License:** MIT
- **Decision-making:** Benevolent dictator for life (BDFL) model for v0.x series

## Planned (v0.3+)

- Core maintainer team (3-5 members)
- Consensus-based decision making on API changes
- Adapter maintainers for specific domain packs
- OpenSSF badge tracked at [bestpractices.coreinfrastructure.org](https://bestpractices.coreinfrastructure.org)
